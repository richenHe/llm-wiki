# 通用学习流程：定 → 图 → 懂 → 联 → 练 → 测 → 迁 → 复

这八步是所有知识共用的学习骨架，但每一步的深度会随知识变化。它不是要求所有内容固定两层，而是规定学习时要解决哪些问题。例如“牛顿第二定律”可以深入公式、实验和适用条件；“公司报销规则”则可以深入流程、例外和凭证。

1. **定：定位。** 先确认当前知识在体系中的位置和目标。例如“加速度”位于“物理 → 力学 → 运动”，学习目标是能判断速度变化的快慢和方向。
2. **图：建图。** 看清父节点、兄弟节点、子节点和跨主题联系。例如“速度”是前置知识，“运动图像”是同层后续应用。
3. **懂：理解。** 用一句精华、一个反例和一个直观模型掌握本质。例如“加速度不是速度大，而是速度改变得快”。
4. **联：连接。** 把新知识接到已有知识和真实场景。例如汽车从 0 加速到 60 km/h，是速度发生变化，而匀速高速行驶的加速度可以为 0。
5. **练：练习。** 从识别、解释到计算或操作逐级练。例如先判断是否有加速度，再计算大小，最后分析方向。
6. **测：检验。** 不看答案，用自己的话复述并解决新问题。例如解释“为什么减速时加速度不一定为负”。
7. **迁：迁移。** 把规律用于不同情境。例如把直线运动中的加速度迁移到圆周运动的方向变化。
8. **复：复习。** 按遗忘风险回到精华节点和错题。例如第二天只看“速 → 加 → 图”并再次口述，而不是重读整章。

## 学习顺序的三种关系

- `⇒` 表示严格前置：后一步必须等前一步。例如不会“速度”时，不应直接计算“加速度”。
- `→` 表示推荐顺序：交换也能理解，但按此顺序更顺。例如咖啡店经营可按“客 → 品 → 场 → 服 → 营 → 财 → 增”。
- `·` 表示并列记忆：没有先后，只是一起记更容易。例如“豆 · 奶 · 糖 · 器”都是“品”下面的子节点。

## 精华概念

每个节点同时保存一个短标签和一段完整解释。短标签用于在脑中串起体系，详情用于避免“只背字、不理解”。例如节点显示“加”，打开后才显示“加速度表示速度变化得有多快”，因此可以用“位、速、加、图”快速回忆运动学结构。
