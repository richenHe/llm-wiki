# 界面设计说明

界面的核心是一只由知识点和关系线组成的镂空球，没有实体球面、地球纹理或装饰性玻璃罩。这样大量线条仍有呼吸空间。例如球体背后的节点会变淡，用户仍能看出球壳深度，但中央背景不会被挡住。

## 全局模式

全局模式展示主要知识领域和少量代表节点。拖动可旋转，滚轮在子节点过多时切换可见窗口，右侧按钮负责缩放。例如知识库有 18 个学科时，球面可以分组展示，而不是固定九个椭圆。

## 聚焦模式

点击节点后镜头平滑靠近，当前节点使用蓝色，直接子节点清晰显示，兄弟节点降低对比度。再次点击子节点继续深入。例如从“力学”进入“运动”，再进入“加速度”，路径面板会同步更新。

## 关系点

跨节点关系使用紫色空心点，不绘制目标小球。默认显示最重要的 5 个，其余合并为 `+N`。例如“加速度”有 14 个跨主题联系时，只显示 5 个点和“+9”，点击具体点直接移动到目标。

## 路线卡

路线卡只在悬停节点或固定路线后出现。它展示同级顺序、当前节点和顺口溜。例如悬停“营”时显示“客 → 品 → 场 → 服 → 营 → 财 → 增”和“识客定品，布场优服；精营明财，持续增长”。

## 减少动态效果

如果系统开启“减少动画”，镜头立即到位，不执行旋转和滑行动画。这是无障碍设置，意思是容易因动画不适的用户也能使用；例如 Windows 开启减少动画后，点击节点会直接切换焦点。
