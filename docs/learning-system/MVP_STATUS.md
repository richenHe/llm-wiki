# MVP 完成范围

## 当前版本包含

- 从现有知识库生成动态深度知识树，并保留全部知识页和章节。例如一个 Markdown 文件的二级到六级标题会继续形成子节点。
- 镂空三维知识球、平滑聚焦、路径与目录导航、搜索、节点详情、兄弟学习路线和跨节点关系点。例如点击关系点可移动到另一个主题，而不是打开第二个球。
- 大量子节点的可见窗口和目录滚动。例如 80 个子节点不会同时绘制，仍能按组浏览全部内容。
- 自我讲解练习和项目级进度保存。例如关闭程序后再次打开，同一项目仍保留已提交的讲解记录。
- “定、图、懂、联、练、测、迁、复”八步导航和每一步的当前任务提示。例如进入“迁”会要求换一个场景使用当前知识；目前只有“测”的自我讲解会保存记录。

## 当前版本尚未包含

- 不会自动判断自我讲解是否正确，只检查是否达到最短长度并保存。例如写满 12 个字但概念错误时，当前版本仍会记录为“已练习”，不会标记为“已掌握”。
- 八步流程还没有逐步完成状态和自动任务判定，除了“测”的自我讲解外，其余步骤是可执行提示。例如“迁”会告诉你换场景应用，但不会自动判断迁移是否成功。
- 不会自动生成高质量押韵口诀，通用知识默认使用短标签串和顺序提示。例如咖啡店示例可以人工配置“识客定品……”，任意新主题暂时只生成清晰但不一定押韵的提示。
- 知识树的归属主要来自知识库社区和文档标题层级，还没有让大模型逐节点审核教学合理性。例如文档本身分类混乱时，系统可以导航，但仍需要后续“教学结构审校”功能纠正父子关系。

## 下一阶段

下一阶段应增加教学结构审校、自动出题与评分、间隔复习计划和人工调整路线。例如系统发现“加速度”被放在“热学”下时，应提出移动建议并让用户确认，而不是静默改动知识库。
