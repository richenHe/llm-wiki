# 通用学习系统

这不是一张静态知识图，而是一套把任何知识变成“可导航、可理解、可练习、可复习”结构的学习系统。它既可以装高中物理，也可以装咖啡店经营、编程语言或公司制度。例如学习咖啡店经营时，第一层可以是“客、品、场、服、营、财、增”，进入“品”后才展开“豆、奶、糖、器”。

## 文档导航

- `LEARNING_FRAMEWORK.md`：固定的通用学习流程。例如每个知识都按“定、图、懂、联、练、测、迁、复”推进。
- `CONTENT_PEDAGOGY_STANDARD.md`：知识点要写到什么程度才真正可学。例如不能只给“损失函数衡量误差”，还要逐词解释、完整演算、迁移例子、反例、流程图、证据摘要和复述练习。
- `FUNCTIONAL_ARCHITECTURE.md`：软件有哪些功能以及功能如何配合。例如知识球负责定位，详情抽屉负责理解，学习模式负责练习。
- `KNOWLEDGE_TREE_SPEC.md`：知识树如何建立、压缩和扩展。例如“实体”只是内部分类，不会成为学习目录。
- `UI_DESIGN.md`：界面与动作规则。例如跨节点只显示一个紫色关系点，点击后平滑移动到目标节点。
- `MVP_STATUS.md`：当前版本已完成和未完成的内容。例如当前能保存自我讲解，但不会自动判断讲解是否正确。

## 一次完整学习示例

以“加速度”为例：先在知识球确认它位于“力学 → 运动”，再查看它的精华解释“速度变化得有多快”；随后联系前置知识“速度”，用生活例子理解刹车和起步，完成一道辨析题，最后用自己的话复述并保存。复习时不必重新读整章，只需从“运 → 速 → 加”唤回结构。
